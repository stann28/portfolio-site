Hardened container deployment on AWS

This site runs as a non-root, capability-dropped NGINX container on ECS Fargate behind an Application Load Balancer, with TLS 1.2+ from ACM, DNS in Route 53 and logs in CloudWatch. No access keys exist anywhere: deploys use short-lived credentials. Every change is built, scanned with Trivy and checked for security headers in CI before it ships.
